# Hada Dental

Proyecto académico desarrollado para la asignatura Desarrollo Web 1.

Autores:
- Sofía Giraldo López
- Sara Isabel Suárez Londoño

Descripción:

Sistema web para el registro de pacientes del Centro Odontológico Hada Dental.

Tecnologías utilizadas:

- HTML
- CSS
- JavaScript

Archivos:

- index.html: formulario principal.
- about.html: información del proyecto.
- style.css: estilos visuales.
- validacion_form.js: validaciones del formulario.
